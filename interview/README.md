# The Dev Café: Interview Exercises

Four short, **independent** exercises. Each folder has its own README with the task and the files it's about.
Nothing needs to be installed: the app, the database and the SQL console are already running in this workspace.

| # | Exercise | Folder | Where in the app |
|---|---|---|---|
| 1 | Understand the request | [`module-1-understand-the-request`](module-1-understand-the-request/README.md) | `product` package (discussion only) |
| 2 | Make it fast | [`module-2-make-it-fast`](module-2-make-it-fast/README.md) | `order` package, `GET /api/customers/{id}/orders` |
| 3 | Review this PR | [`module-3-review-this-pr`](module-3-review-this-pr/README.md) | `reporting` package (PR on its own branch) |
| 4 | When things go wrong | [`module-4-when-things-go-wrong`](module-4-when-things-go-wrong/README.md) | `sale` + `analytics` packages, `BuyButton.jsx` |
