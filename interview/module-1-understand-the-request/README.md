# Module 1: Understand the Request

This one is a conversation. There is nothing to build.

## The ticket

A product manager sends you this:

> *"On the product page, add a Buy button. When someone buys, the stock count should go down.
> And marketing wants to know about every sale."*

That's the whole ticket. **Before you write anything, what would you ask them?**
